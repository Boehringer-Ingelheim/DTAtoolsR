iris.sas7bdat in this directory is an unmodified copy of the example file
shipped with the haven R package (system.file("examples", "iris.sas7bdat",
package = "haven"); 131072 bytes), https://github.com/tidyverse/haven

Provenance: written by SAS 9.04.01M2 on X64_8PRO. Its four numeric columns
(Sepal_Length, Sepal_Width, Petal_Length, Petal_Width) are bit-identical to the
first four columns of datasets::iris; Species is stored as $6, so the values
are "setosa", "versic" and "virgin".
